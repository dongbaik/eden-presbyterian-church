# 갤러리에 표시할 구글 포토 앨범 목록  (Google Photos albums shown in the gallery)
#
# 사용법
#   1. 구글 포토(media@oregoneden.com)에서 앨범을 열고 "공유" → "링크 만들기"
#      → 링크를 복사해서 아래에 한 줄씩 붙여넣습니다.
#   2. 터미널에서 실행 (저장소 루트에서):
#      tools/photos/.venv/bin/python .github/skills/update-gallery/scripts/sync_albums.py
#      또는 그냥 에이전트에게 "갤러리 업데이트" 라고 말하세요.
#   3. 제목 · 날짜 · 커버 사진이 자동으로 수집되어 gallery.html 이 갱신됩니다.
#
# 순서 = 갤러리에 표시되는 순서입니다. 최신 앨범을 맨 위에 두세요.
# '#' 로 시작하는 줄과 빈 줄은 무시됩니다.
#
# 앨범 제목/날짜를 직접 지정하고 싶으면 ' | ' 로 덧붙이세요 (선택 사항):
#
#   <링크> | 여름 청소년 수련회 | 2026. 7. 14 – 21
#   <링크> | 여름 청소년 수련회            (제목만 덮어쓰기, 날짜는 자동)
#
# 링크만 적으면 앨범 이름에서 "제목 · 날짜" 를 자동으로 분리합니다.
# 아래 주석의 이름은 참고용이며, 실제 제목은 앨범에서 자동으로 가져옵니다.
